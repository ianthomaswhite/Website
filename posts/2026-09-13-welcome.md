Welcome to my revamped personal website. 

For the past several years, the modern web has succumbed to an exhausting regime of bloated JavaScript frameworks, tracking beacons, dynamic ad-tech telemetry, and homogenized template designs. This site represents a deliberate departure from that model toward **brutalist minimalism** and **type-safe static generation**.

## Principles Behind This Site

1. **Zero-Bloat Minimalism:** No client-side framework overhead. Pages are standard HTML5 and CSS, styled with sharp geometric lines and a high-voltage `#FCF75E` accent.
2. **Haskell & Hakyll Engine:** Everything is synthesized using **Hakyll**, a static site generator written in Haskell. The site build is a pure, reproducible function mapping source text to static artifacts.
3. **Continuous LaTeX Pipeline:** Research papers, essays, and resumes are maintained as rigorous LaTeX documents, compiled directly to publication-grade PDFs via GitHub Actions.
4. **Decoupled Architecture:** While the core portfolio and blog remain strictly static on GitHub Pages, future interactive systems—such as an IPA comparative Indo-European lexicon and AI resume synthesis engines—will integrate as dedicated microservices under subdomains.

## Code and Content

Here is an example of what Hakyll route composition looks like in Haskell:

```haskell
match "posts/*" $ do
    route $ setExtension "html"
    compile $ pandocCompiler
        >>= loadAndApplyTemplate "templates/post.html"    postCtx
        >>= loadAndApplyTemplate "templates/default.html" postCtx
        >>= relativizeUrls
```
